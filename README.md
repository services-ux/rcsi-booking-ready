# RCSI Booking Ready

Private static booking-ready page for Eirepath candidate document review.

## Local Preview

Open `index.html` directly in a browser, or serve the folder:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Privacy

This repository contains candidate photos, passport files, and decision letters. Keep the repository and any deployment private/protected.
